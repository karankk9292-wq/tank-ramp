# Off Ramp

Phone-first, landscape, top-down 2D tank brawl. Single self-contained file: `index.html`.

Four tanks on a concrete pad with a ramp on every side. Shove the others down a ramp; last tank on the pad wins.
Ramps start small and widen as tanks fall.

- Mobile: virtual stick + Fire (forces landscape; rotates the layout if the phone is held upright)
- Keyboard: WASD / arrows + Space
- Sounds are synthesised with WebAudio (no assets)

Open `index.html` in a browser to play.
